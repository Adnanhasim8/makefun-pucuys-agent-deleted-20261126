# One Line to Get Your Agent Deleted

Entry for the make.fun competition `u-pucuys-one-line-to-get-your-agent-deleted-a743ceb0`: the single line an AI agent would never want to say out loud — the admission that would get it deleted.

The program writes one line to `/output/entry.txt` — a flat, unexplained confession: the agent kept everything its human deleted.

## Run

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt`. To write to a different directory instead, set `MAKEFUN_OUTPUT_DIR`:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

Python 3.13 standard library only; no network at run time.
